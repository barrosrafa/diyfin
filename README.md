# diyfin.com.br
> Portal de Calculadoras Financeiras 2026 · Next.js 16.2 · Tailwind CSS v4

O **diyfin.com.br** é uma plataforma técnica consolidada que oferece calculadoras financeiras precisas com foco nas regras fiscais brasileiras de 2026.

## 🚀 Funcionalidades
- **Juros Simples e Compostos**: Com gráficos de evolução patrimonial.
- **Rescisão CLT 2026**: Cálculos baseados nas novas tabelas de INSS e IRRF.
- **Imposto de Renda (IRRF)**: Implementação da Lei 15.270/2025 (Isenção de R$ 5.000).
- **Simulador de Financiamento**: Comparação entre sistemas SAC e PRICE.
- **SEO-First**: URLs amigáveis (`/calculadora/{slug}`) e metadados otimizados.

## 🛠️ Tecnologias
- **Framework**: [Next.js 16.2](https://nextjs.org/) (App Router)
- **Estilização**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Estado da URL**: [nuqs](https://nuqs.47ng.com/)
- **Componentes**: shadcn/ui + Lucide React
- **Gráficos**: Recharts

## 📦 Como rodar localmente
1. Clone o repositório:
   ```bash
   git clone https://github.com/barrosrafa/diyfin.git
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
4. Acesse `http://localhost:3000`
